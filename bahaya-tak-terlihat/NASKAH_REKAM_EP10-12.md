# Naskah Rekam VO: EP10–12 (suara kamu sendiri)

## Cara rekam (5 menit persiapan)
- **Tempat:** kamar yang sunyi dan banyak barang empuk (kasur, lemari baju). Matikan kipas dan AC.
- **HP:** jarak sekitar sejengkal (15–20 cm) dari mulut, sedikit di bawah dagu supaya napas tidak "bletak" ke mic.
- **Aplikasi:** perekam suara bawaan HP, kualitas tertinggi.
- **File:** 1 file per episode. Kalau salah baca, **diam 2 detik lalu ulang kalimat itu dari awal**. Nanti saya yang potong.
- **Gaya:** seperti cerita ke teman atau adik. Jangan seperti membaca berita. Senyum saat bagian ringan, pelan dan lembut di bagian 🤍.
- **Tanda di naskah:**
  - `/` jeda singkat (setengah detik)
  - `//` jeda panjang (1 detik)
  - **tebal** = kata yang ditekan
  - *(miring dalam kurung)* = arahan nada, tidak dibaca
- Kirim file mentahnya saja (m4a/mp3/wav). Pembersihan suara, pengaturan tempo, caption, dan sinkron ke animasi saya yang kerjakan.

## EP10: "Jangan Langsung Pegang!"

**HOOK** *(serius, pelan, langsung masuk)*
> Seorang ibu lari nolongin anaknya yang **kesetrum**… / dan dua-duanya **nggak selamat**. //

**ISI**
> *(bercerita)* Simalungun, tahun dua ribu dua puluh satu. /
> Lagi jemur baju, anaknya kesetrum di **kawat jemuran**. /
> Ibunya refleks narik tangan anaknya… / dan **ikut kesetrum**. //
>
> Ternyata, ada **kabel listrik putus** yang nyentuh atap seng. /
> Dan seng itu nyambung ke kawat jemuran. //
>
> *(berbisik, misterius)* Itu ulah makhluk halus paling cepat… /
> *(semangat)* **Listrik nyasar!** //
>
> Arus sekecil tiga puluh sampai lima puluh miliampere aja / udah bisa **ganggu jantung**. /
> Apalagi kalau badan lagi **basah**. //
>
> *(tegas, seperti memberi aba-aba)* Jadi, kalau ada orang kesetrum, / **jangan langsung dipegang**. /
> Matiin dulu **MCB** di meteran. /
> Kalau nggak sempat, dorong pakai **kayu** atau **sapu kering**, / sambil berdiri di alas yang kering. //
>
> Terus, cek rumah kamu. / Kabel yang ngelupas. / Colokan numpuk kayak **sate**. / Kawat jemuran yang deket kabel atau atap seng. //
>
> Pasang **ELCB** *(baca: e-el-ce-be)*. / Alat kecil ini motong listrik dalam hitungan **milidetik**, / begitu ada arus bocor ke badan. /
> Harganya jauh lebih murah dari **nyawa**. //
>
> Dan kalau rumah **kebanjiran**, / matiin listrik dulu sebelum beres-beres. //
>
> 🤍 *(pelan, lembut, ambil napas dulu)* Ibu itu **nggak salah**. /
> Dia cuma ngelakuin yang semua ibu bakal lakuin. //
> Tugas kita… / bikin rumah yang nggak bikin dia **harus milih**. //
>
> *(kembali santai)* Follow, / biar bahaya yang nggak kelihatan… / jadi kelihatan. //

**AJAKAN KOMEN** *(hangat, seperti titip pesan)*
> Simpan video ini, / terus kirim ke grup keluarga. / Siapa tahu suatu hari, / ini yang nyelametin nyawa.

## EP11: "100 Jam Seminggu, Tanpa Gaji"

**HOOK** *(pelan, sedikit tertahan, jeda sebelum "Ibu")*
> Ada pekerjaan yang jamnya bisa **seratus jam seminggu**… / nggak digaji, / nggak ada cuti. // Dan kamu manggilnya: / **Ibu**. //

**ISI**
> *(cepat, seperti daftar panjang tanpa habis)* Bangun sebelum subuh. Masak, nyuci, nganter anak, belanja, beresin rumah, ngurus yang sakit… /
> *(melambat)* terus kalau ditanya kerja apa, jawabnya: / *(kecil, merendah)* "cuma ibu rumah tangga." //
>
> *(serius)* Padahal, eksperimen **ILO** *(baca: i-el-o)* bareng Magdalene nyatet: /
> ada perempuan yang kerja ngurus keluarganya lebih dari **seratus jam** seminggu. /
> **Empat dari lima** peserta, / di atas empat puluh jam. /
> Itu udah **lewat batas** jam kerja di undang-undang. //
>
> Dan di seluruh dunia, / lebih dari **tiga perempat** kerja ngurus keluarga yang nggak dibayar, / dikerjain perempuan. //
>
> Bahayanya nyata, / cuma nggak kelihatan. /
> Ngangkat galon sama ember cucian, / kena **pinggang**. /
> Jongkok nyuci berjam-jam, / kena **lutut**. /
> Tidur kepotong tiap malam, / badan **nggak pernah pulih**. //
>
> *(berbisik)* Itu ulah makhluk halus yang satu ini… / *(tegas)* **Beban yang nggak kelihatan!** //
>
> *(lebih ringan, memberi solusi)* Terus gimana? / Bagi kerjaannya. / Galon, ember, belanjaan berat… / **angkat berdua**. /
> Nyuci jangan jongkok lama, / pakai **bangku kecil**. /
> Kasih ibu waktu **tidur siang**, / satu jam aja. //
>
> Dan buat yang kerja kantor sekaligus ngurus rumah, / kamu kerja **dua shift**. / Wajar kalau capek. //
>
> 🤍 *(pelan sekali, tulus)* Ibu nggak minta digaji. /
> Dia cuma butuh **dibantu**… / dan dibilang **makasih**. //
>
> *(kembali santai)* Follow, / biar bahaya yang nggak kelihatan… / jadi kelihatan. //

**AJAKAN KOMEN** *(hangat)*
> Kirim video ini ke ibu kamu, / terus bilang makasih. / Atau tulis di komen: / kerjaan rumah apa yang hari ini kamu ambil alih?

## EP12: "Lantai Kamar Mandi Basah?"

**HOOK** *(pelan, serius)*
> Satu langkah di lantai kamar mandi yang licin… / bisa bikin orang tua kita **nggak bisa jalan lagi**. //

**ISI**
> *(bercerita, suasana malam)* Kakek atau nenek kamu, / bangun malam mau ke kamar mandi. /
> Lampu redup, / lantai basah, / buru-buru… / terus **kepeleset**. //
>
> Buat orang muda, / mungkin cuma memar. /
> Buat lansia, / bisa **patah tulang panggul**. / Dan banyak yang **nggak pernah bisa jalan normal lagi**. //
>
> *(berbisik)* Itu ulah makhluk halus yang suka nongkrong di lantai basah… / *(tegas)* **Lantai licin!** //
>
> *(serius, jelas)* **WHO** *(baca: we-ha-o)* nyatet: / jatuh itu penyebab kematian karena cedera tak disengaja **nomor dua** di dunia, / setelah kecelakaan lalu lintas. /
> Sekitar **enam ratus delapan puluh empat ribu** orang meninggal tiap tahun. /
> Paling banyak, / umur enam puluh ke atas. //
>
> *(lebih cerah)* Kabar baiknya, / kebanyakan jatuh itu **bisa dicegah**. /
> Pasang keset **anti-slip**. / Pasang **pegangan** di dinding kamar mandi. / Nyalain **lampu kecil** buat malam. /
> Singkirin kabel sama barang dari jalur jalan. / Pakai **sandal karet** yang nggak licin. /
> Dan kalau orang tua mulai sering **pusing** pas berdiri, / ajak periksa. //
>
> Biayanya cuma **ratusan ribu**. / Yang diselametin: / tahun-tahun mereka masih bisa **jalan sendiri**. //
>
> 🤍 *(pelan, hangat, sedikit tersenyum)* Dulu, / mereka yang megangin tangan kita waktu belajar jalan. //
> Sekarang… / **giliran kita**. //
>
> *(kembali santai)* Follow, / biar bahaya yang nggak kelihatan… / jadi kelihatan. //

**AJAKAN KOMEN** *(akrab)*
> Tag saudara kamu: / rumah siapa yang paling perlu pegangan di kamar mandi? / Tulis di komen.

### Durasi target
Masing-masing sekitar **60–70 detik** kalau dibaca santai. Kalau hasilnya kurang dari 60 detik, tidak apa-apa; nanti saya atur tempo dan jedanya supaya tetap di atas 1 menit.
